# AI Expense Assistant

An AI-powered assistant that analyzes bank/UPI statements and answers natural-language questions about your spending — built for quick, conversational expense insights in Indian Rupees (₹).

> **Status: hackathon-quality prototype.** Built to demonstrate an LLM-driven expense analysis flow, not a production financial product.

## Overview

Upload a bank or UPI statement (PDF or CSV) and the assistant extracts transactions, categorizes them, and lets you ask questions like *"Where am I overspending?"* or *"How can I save money?"* in plain language. Responses are generated by an LLM API call over your parsed transaction data — not a static rules engine.

## Features

- **Statement upload** — PDF or CSV bank/UPI statements, with a visible processing state during extraction
- **Sample data mode** — load a demo dataset instantly without uploading anything
- **AI-driven categorization** — transactions are grouped into categories (UPI/Transfers, Shopping, Utilities, Food & Dining, Other) via an LLM call, not hardcoded keyword rules
- **Visual category breakdown** — interactive donut chart showing ₹ amount and percentage per category
- **Conversational Q&A** — ask free-form questions about your spending; suggested prompts include "Total spending this month," "Find unnecessary expenses," and "How can I save money?"
- **Localized onboarding** — bilingual welcome screen (English / Hindi)
- **All amounts in ₹ INR**

## How It Works

1. User uploads a PDF/CSV statement, or loads sample data
2. The app extracts transaction records (date, amount, description, etc.)
3. Transaction data is sent to an LLM API, which returns categorized transactions
4. Categorized data renders as a chart and feeds the chat interface
5. User questions are answered by the LLM with the categorized data as context

## Privacy

The UI states: *"No data stored on servers · AI explanations only."* This reflects the intended design — statements are processed for the session and not persisted in a database.

**Caveat:** uploaded statement data is sent to a third-party LLM API for categorization and Q&A, which is a necessary part of how the AI features work. If you're evaluating this for real financial data, check the specific LLM provider's data retention and training-use policy for API calls before uploading actual statements.

## Known Limitations

- No authentication or multi-user support
- No persistent transaction history across sessions
- Categorization logic is fully LLM-dependent — if the LLM API is unavailable, the app may not gracefully degrade (no confirmed fallback path)
- Not intended for use with real banking data without further privacy/security review
